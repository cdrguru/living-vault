# Security policy

## Reporting a vulnerability

Please do NOT open a public issue for anything security-sensitive. Use
GitHub's private vulnerability reporting on this repository (Security tab,
"Report a vulnerability"). You will get an acknowledgement within a few
days.

## Scope notes

- The app is local-first: collectors are metadata-only and nothing a user
  measures leaves their machine by default. Anything that violates that
  contract is a vulnerability; report it.
- The demo deployment serves synthetic data only.
